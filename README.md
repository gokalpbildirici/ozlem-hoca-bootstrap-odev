# OKÜ Student Club Website

[English](README.md) | [Türkçe](README.tr.md)

A modern, responsive web interface built with Bootstrap 5.3 for the student clubs of Osmaniye Korkut Ata University.

## Features

- **Responsive Design:** Fully compatible with mobile, tablet, and desktop devices.
- **Bootstrap 5.3:** Modern components and flexible grid system.
- **Icon Support:** Enriched visual structure using the Lucide icon library.
- **Club Management:** Dedicated detail pages, event calendar, and application forms.
- **Modern Interface:** Professional typography and a clean color palette.

## Installation and Usage

1. Clone the repository: `git clone <repo-url>`
2. Navigate to the project directory: `cd ozlem-hoca-bootstrap-odev`
3. Serve the project locally or open `index.html` directly in your browser.

## Tech Stack

- HTML5
- CSS3 (Bootstrap 5.3)
- JavaScript
- Lucide Icons
