# OKÜ Kulüp Sitesi

[English](README.md) | [Türkçe](README.tr.md)

Bootstrap 5.3 tabanlı, Osmaniye Korkut Ata Üniversitesi öğrenci kulüpleri için geliştirilmiş modern ve responsive web arayüzü.

## Özellikler

- **Responsive Tasarım:** Mobil, tablet ve masaüstü cihazlar için tam uyumlu.
- **Bootstrap 5.3:** Modern bileşenler ve esnek grid yapısı.
- **İkon Desteği:** Lucide ikon kütüphanesi ile zenginleştirilmiş görsel yapı.
- **Kulüp Yönetimi:** Kulüplere özel detay sayfaları, etkinlik takvimi ve başvuru formları.
- **Modern Arayüz:** Profesyonel tipografi ve temiz renk paleti.

## Kurulum ve Kullanım

1. Depoyu klonlayın: `git clone <repo-url>`
2. Proje klasörüne gidin: `cd ozlem-hoca-bootstrap-odev`
3. Projeyi bir web sunucusu üzerinde veya doğrudan `index.html` dosyasını tarayıcıda açarak çalıştırın.

## Teknoloji Yığını

- HTML5
- CSS3 (Bootstrap 5.3)
- JavaScript
- Lucide Icons
